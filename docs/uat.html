User Acceptance Testing (UAT)

Aplikasi: QAYRA FACIAL ANALYZING — by Qayra Make Up. Pengujian penerimaan dari sudut pandang pengguna akhir. Role penguji konsisten dengan aktor use case: Client (User) dan Admin Qayra.

NoSkenario PengujianRole yang MengujiFitur yang Diuji Langkah PengujianEkspektasi HasilStatus (Pass/Fail)
1 Client masuk ke aplikasi menggunakan akun yang diberikan admin Client UC01 — Login Buka aplikasi → isi email & password → tekan LOGIN Berhasil masuk dan melihat Dashboard berisi informasi client & status terakhir Pass
2 Client keluar dari aplikasi setelah selesai Client UC02 — Logout Tekan ikon logout → pilih "Ya, Keluar" Kembali ke halaman Login dan sesi berakhir Pass
3 Client mengecek kondisi kulit wajah sebelum acara dengan mengambil foto Client UC03 — Melakukan Analisis Kulit Wajah Buka menu Kamera → ambil foto wajah → konfirmasi foto → tunggu proses Muncul hasil kondisi kulit (mis. "Oily Skin") beserta tingkat keyakinan & rekomendasi Pass
4 Client mengunggah foto dari galeri untuk dianalisis Client UC03 — Melakukan Analisis Kulit Wajah Buka Kamera → tekan Upload → pilih foto → konfirmasi Foto dianalisis dan hasilnya tersimpan ke riwayat Pass
5 Client melihat seluruh riwayat pengecekan kulitnya Client UC04 — Melihat Riwayat Analisis Buka menu Riwayat Daftar analisis tampil terurut dari yang terbaru lengkap dengan tanggal & status Pass
6 Client membuka detail salah satu hasil analisis Client UC05 — Melihat Detail Hasil Analisis Pada Riwayat, tekan tombol detail pada salah satu baris Tampil ringkasan hasil, catatan klinis, prioritas perawatan, protokol persiapan, distribusi probabilitas, & foto Pass
7 Client mengunduh laporan hasil analisis untuk dibawa ke perias Client UC06 — Mengunduh Laporan PDF Buka detail analisis → tekan tombol Download Berkas PDF berisi laporan analisis terunduh ke perangkat Pass
8 Admin menambahkan catatan khusus pada hasil analisis klien Admin UC07 — Menambahkan Catatan Qayra Buka detail analisis → tulis catatan pada kolom Catatan Qayra → tekan Simpan Catatan Muncul notifikasi "Catatan Tersimpan" dan catatan tersimpan permanen Pass
9 Admin memantau ringkasan jumlah klien, admin, dan analisis Admin UC08 — Melihat Dashboard Admin Login sebagai admin → buka Dashboard Tampil kartu Total Client, Total Admin, Total Analisis, serta daftar Analisis Terbaru Pass
10 Admin mendaftarkan akun klien baru beserta tanggal acara Admin UC09 — Mengelola Data User (Tambah) Menu User → Tambah User → isi data → konfirmasi "Ya, Daftarkan" Akun klien baru berhasil dibuat dan muncul di daftar user Pass
11 Admin memperbarui data atau menonaktifkan akun klien Admin UC09 — Mengelola Data User (Edit) Menu User → pilih user → Edit → ubah data/status → Simpan Perubahan data user tersimpan dan terlihat di daftar Pass
12 Admin menghapus akun klien yang tidak diperlukan Admin UC09 — Mengelola Data User (Hapus) Menu User → tekan hapus pada user → konfirmasi "Ya, Hapus" User terhapus dari daftar (akun sendiri tidak bisa dihapus) Pass
13 Admin menelusuri dan membuka data analisis seluruh klien Admin UC10 — Mengelola Data Analisis (Lihat/Cari) Menu Analisis → ketik nama/email pada kolom cari → buka detail Data analisis terfilter sesuai pencarian dan detail dapat dibuka Pass
14 Admin menghapus data analisis yang sudah tidak relevan Admin UC10 — Mengelola Data Analisis (Hapus) Menu Analisis → tekan hapus → konfirmasi "Ya, Hapus" Data analisis terhapus dan daftar diperbarui Pass
