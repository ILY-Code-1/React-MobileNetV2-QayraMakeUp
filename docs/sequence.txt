' == Sequence: UC01 Login ==
@startuml
title Sequence - UC01 Login
actor "Client/Admin" as User
participant "LoginPage" as UI
participant "authStore /\nfirestoreService" as Ctrl
database "Firestore\n(users_qayra)" as DB

User -> UI : Mengisi email & password, klik LOGIN
activate UI
UI -> Ctrl : login(email, password)
activate Ctrl
Ctrl -> DB : query user by email
activate DB
DB --> Ctrl : data user
deactivate DB
alt Kredensial valid & aktif
  Ctrl -> DB : update lastLoginAt
  Ctrl --> UI : data user (sesi disimpan)
  UI --> User : Tampilkan Dashboard
else Tidak valid
  Ctrl --> UI : Error "Email atau password salah"
  UI --> User : Tampilkan pesan error
end
deactivate Ctrl
deactivate UI
@enduml
