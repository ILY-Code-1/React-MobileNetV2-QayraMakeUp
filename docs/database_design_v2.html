Desain Basis Data Relasional (ERD → LRS)

Aplikasi: QAYRA FACIAL ANALYZING — by Qayra Make Up
Catatan: Dokumen ini menormalisasi struktur dokumen Firestore (users_qayra, analysis_qayra) ke dalam model relasional konseptual untuk keperluan akademik/dokumentasi. Atribut array & map yang tersematkan (embedded) dipecah menjadi tabel tersendiri.

1. Entity Relationship Diagram (ERD)

Domain QAYRA terdiri dari lima entitas utama. User adalah klien atau admin; setiap User dapat memiliki banyak Analysis (one-to-many). Setiap Analysis menghasilkan distribusi probabilitas terhadap lima jenis kondisi kulit, sehingga terbentuk relasi many-to-many antara Analysis dan SkinConditionClass. Selain itu, satu Analysis memiliki banyak baris TreatmentPriority (prioritas perawatan) dan banyak baris PreparationStep (langkah protokol persiapan) — keduanya merupakan weak entity yang keberadaannya bergantung pada Analysis.

2. Transformasi ERD ke LRS (Logical Record Structure)

Aturan transformasi yang diterapkan terhadap ERD di atas:

  • One-to-Many User → Analysis: Foreign Key user_id ditempatkan di sisi "many", yaitu tabel Analysis.
  • One-to-Many SkinConditionClass → Analysis (kelas dominan): FK predicted_label ditempatkan di tabel Analysis dan merujuk ke SkinConditionClass.class_key.
  • Many-to-Many Analysis ↔ SkinConditionClass: menghasilkan tabel junction baru AnalysisClassProbability dengan composite primary key (analysis_id + class_key) ditambah atribut relasi probability dan rank. Tabel ini menormalisasi array modelOutputRaw dan topClasses dari Firestore.
  • Multivalued attribute treatmentPriority[]: dipisah menjadi tabel TreatmentPriority (weak entity) dengan FK analysis_id dan PK gabungan (analysis_id + sequence_no).
  • Nested multivalued preparationProtocol{7_days_before,3_days_before,day_of_makeup}: dipisah menjadi tabel PreparationStep (weak entity) dengan PK gabungan (analysis_id + phase + sequence_no).
  • Weak entity: PK tabel TreatmentPriority dan PreparationStep mewarisi FK analysis_id dari Analysis sebagai bagian dari composite key.
